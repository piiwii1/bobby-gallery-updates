# PiiWii TV Phone 0.4.0

Application Android native (sans WebView).

## 0.4.0
- Guide TV natif via `/wp-json/geektv/v1/epg?hours=54`
- cache EPG local
- filtres Maintenant / Ce soir / Demain
- accès à une chaîne depuis un programme en direct
- menu inférieur fixe Direct / Guide / Réglages
- menu placé au-dessus de la barre Android grâce aux WindowInsets
- affichage du programme en cours dans les cartes Direct
- `epg_id` des chaînes pris en charge pour le mapping EPG
- Media3 / ExoPlayer conservé
